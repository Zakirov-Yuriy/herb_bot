# Автосбор ресурсов + авто-бой (omela_bg.py)

Бот открывает **своё** игровое окно и кликает внутри страницы (окно можно свернуть).
Собирает ресурс **выбранной профессии**, прокручивает карту, ведёт бой при нападении
монстра, закрывает окна-ошибки и не тыкает чужие ресурсы.

**Профессии:**

- `herbalist` — **травник**: омела/травы (жёлто-зелёный куст, режим по умолчанию).
- `geolog` — **геолог**: драгоценные камни/руда (несколько ярких цветов).
- `fisher` — **рыбак**: рыба (пресет-заготовка, лучше уточнить пипеткой).

Ресурс распознаётся по цвету. Для каждой профессии есть встроенный пресет цветов,
но **надёжнее снять цвет «пипеткой»** прямо из игры (Этап 0 калибровки) — особенно
для камней, которые бывают разного цвета.

> ⚠️ Автоматизация нарушает правила онлайн-игр и может привести к бану. На свой риск.

## Установка (один раз)

```
pip install -r requirements.txt
playwright install chromium
```

## Порядок настройки

1. **Вход в игру:** `python omela_bg.py --login` — войди, дойди до локации, ENTER.
2. **Профессия:** `python omela_bg.py --prof geolog` — выбрать, что собирать
2. **Профессия:** `python omela_bg.py --prof herbalist` --prof herbalist травник 
Сменить профессию — только через --prof <имя> (geolog / herbalist / fisher).
   (`herbalist` / `geolog` / `fisher`). Можно пропустить и выбрать в мастере (Этап 0).
3. **Калибровка:** `python omela_bg.py --calib` — пройди мастер (см. ниже). На Этапе 0
   выбери профессию и по желанию сними цвет камней/рыбы пипеткой.
4. **Работа:** `python omela_bg.py` — сбор + бой. Стоп: **Ctrl+C**.
   Либо через окно с настройками — `python launcher.py` (см. «Меню запуска» ниже).

> 🎚 **Чувствительность распознавания:** `python omela_bg.py --sens 0.8` — если бот
> **пропускает** тусклые ресурсы, поставь значение **меньше 1** (мягче, видит больше).
> Если **тыкает лишнее** (траву/фон) — значение **больше 1** (строже). Норма — `1.0`.
> Значение сохраняется в конфиг. Подбирать удобно вместе с `--debug` (см. ниже).

> Профессия и снятый цвет сохраняются в `fight_zones.json`, так что настраивать это
> нужно один раз. При смене профессии старый снятый цвет сбрасывается автоматически.

## Меню запуска — `python launcher.py`

Чтобы не запускать бота из командной строки и не править константы руками, есть
окно с настройками: **`python launcher.py`** (или двойной клик по файлу — `tkinter`
входит в стандартный Python, ставить ничего не нужно).

В окне настраивается **перед запуском**:

- **Профессия** — выпадающий список (травник / геолог / рыбак).
- **Чувствительность** — ползунок распознавания (`<1` мягче, `>1` строже).
- **Время работы, мин** — сколько крутить бота (по умолчанию 240).
- **Авто-крафт** — галочка вкл/выкл (это и есть «собирать **с** крафтом или **без**»),
  плюс «крафтить сразу при запуске» и «крафтить каждые N сек».
- **Бой** — авто-бой и реакция на «занозу»/лечение.

Кнопки: **«Сохранить и запустить»** пишет настройки и стартует `omela_bg.py` в
**отдельном окне консоли** (там нажми ENTER для старта, как обычно); **«Только
сохранить»** — просто сохраняет; **«Калибровка»** — запускает мастер `--calib`.

Настройки складываются в тот же `fight_zones.json`: профессия и чувствительность —
как раньше (ключи `profession` / `sensitivity`), а тумблеры меню — в раздел
`run_config`. При старте сбора бот подтягивает их (`apply_run_config`) и
переопределяет константы из кода. Меню **не заменяет** калибровку — точки
крафта/боя всё так же снимаются через `--calib`. Тестовые режимы (`--testcraft`
и т.п.) настройки меню намеренно игнорируют, чтобы ими можно было проверять крафт
независимо от галочки.

## Мастер калибровки — `python omela_bg.py --calib`

Проходишь **этапы по порядку**, любой можно пропустить (ENTER без клика). Всё
сохраняется в `fight_zones.json`; можно запускать мастер несколько раз — уже снятые
точки не теряются.

**Этап 0. Профессия и цвет ресурса.** Выбери профессию (номер или имя:
`herbalist` / `geolog` / `fisher`). Затем — **«пипетка сбора»** (шаг 1.2): бот
спросит, сколько образцов цвета снять, и ты кликаешь **прямо по ресурсу, который
хочешь собирать**. Правило простое: **один клик — один цвет**. Для ресурса одного
цвета хватит 1 образца; для камней разного цвета сними по одному образцу **на
каждый цвет** (2–4), диапазоны суммируются. Бот запомнит эти цвета и будет искать
только их. Введёшь `0` — цвет вручную не снимаем, остаётся встроенный пресет
профессии (для травы обычно ок; для камней/рыбы пипетку пройти надёжнее).

> Совет по пипетке: бери **яркий, крупный** экземпляр и кликай **один раз ровно по
> центру** ресурса (не по краю и не по траве рядом), затем ENTER. По тусклому или
> наполовину скрытому ресурсу цвет снимется смазанным.

**Этап 0б. «Пипетка игнора» (шаг 1.3, по желанию).** Сразу после пипетки сбора бот
спросит, сколько образцов **фона** снять. Нужно **только если бот ошибается** —
тыкает по траве, фону или по чужим ресурсам. Тогда **кликай прямо по ним**, и эти
цвета попадут в чёрный список: пятна такого цвета собираться не будут. Важно:
исключение учитывает и **яркость**, так что яркий камень того же оттенка, что трава
(например, изумруд), от этого **не пострадает**. Ввести `0` — пропустить,
`c` — очистить ранее снятые исключения.

> ⚠️ **Главное правило игнора:** здесь **нельзя** кликать по ресурсу, который сам
> собираешь — иначе его цвет попадёт в чёрный список и бот перестанет его собирать
> (будет только крутить карту). Кликай **только** по траве/фону/чужому. Бот
> подстрахует и не даст занести цвет ресурса, а при старте ещё и **сам отбросит**
> из игнора цвет, совпавший с ресурсом (напишет об этом в лог). Если сомневаешься —
> введи `0` и пропусти этот шаг, а при проблемах позже нажми **«Очистить игнор»**
> в `launcher.py`.

**Этап 1. Область карты.** Кликни левый-верхний, затем правый-нижний угол зелёной
карты. Бот будет искать ресурсы только внутри этого прямоугольника.

**Этап 2. Способ добычи.** Введи в терминале, сколько кликов запускают добычу —
**1 или 2** (в этой игре — 2). Важно: бот больше не тыкает один и тот же куст
повторно, пока идёт добыча, поэтому добыча не отменяется сама.

**Этап 3. Кнопка «закрыть».** Кликни по чужому ресурсу (который твоя профессия НЕ
добывает), чтобы вылезло окно «Ошибка… нет профессии», и кликни его кнопку
**«закрыть»**. Дальше бот жмёт
эту точку сам — но только когда там появляется красная кнопка (т.е. окно открыто),
поэтому по пустой карте он не кликает и добычу не сбивает.

**Этап 4. Зоны боя.** Нужно быть **в бою** (видно колесо «БЛОК»). Кликни: зону
блока, зону атаки, «выход» (после победы), «В охоту». Нет боя сейчас — пропусти
этот этап (ENTER) и пройди его позже, когда будет бой.

> 🩹 **Заноза — только СВОЯ.** Бот просит вытащить занозу ТОЛЬКО когда игра пишет
> системную строку-награду о твоей занозе — надёжный маркер **«Получено: Заноза»**
> (напр. «Обнаружив драгоценный камень… вонзились вам в руку. **Получено: Заноза 1 шт.**»).
> Запасной путь — строки, начинающиеся с «Вы …заноз…». Чужие ники (напр. игрок
> «Заноза-Буля»), чужие и личные сообщения (со знаком «»»), просьбы «дерните занозу»
> и строку лечения «Вы избавились от занозы» бот игнорирует. Если в твоей игре текст
> о занозе другой — допиши надёжный кусок в `SPLINTER_SELF_MARKERS` (или начало строки
> в `SPLINTER_SELF_PREFIXES`) вверху `omela_bg.py`. В логе видно строку-триггер:
> «🩹 ЗАНОЗА! Сработала строка: …».

**Этап 5. Заноза — авто-возврат кирки.** Рюкзак → вкладка «вещи» → навести на
кирку → «надеть» → режим охоты. Можно пропустить.

**Этап 6. Авто-крафт рецептов.** Кликни кнопку **«профессии»** (которая открывает
панель с рецептами). Затем **сам открой панель** в игре и кликни кнопку **«Создать»**
у **каждого** рецепта по очереди (пустой ENTER — закончить список). В конце кликни
кнопку **«Вернуться»** (выход из панели к сбору). Можно пропустить (ENTER) — тогда
авто-крафт останется выключенным.

## Авто-крафт рецептов (панель профессии)

Пока бот собирает ресурсы, он **периодически** (по умолчанию каждые **5 мин 30 сек**,
`CRAFT_EVERY_SEC = 330`) заходит в панель профессии и жмёт **«Создать»** у каждого
рецепта из «Избранных», затем **«Вернуться»** к сбору. При запуске бот крафтит
**сразу** (`CRAFT_ON_START`). После каждого «Создать» экран сам перезагружается —
бот ждёт (`CRAFT_RELOAD_WAIT`) и только потом жмёт следующий рецепт, как ты и просил.

Что нужно один раз: пройти **Этап 6** мастера `--calib` (снять кнопку профессии,
кнопки «Создать» и «Вернуться»). Проверить настройку разом:
`python omela_bg.py --testcraft` — бот один раз прогонит всю последовательность,
смотри в игре, всё ли нажимается. Рецепты на кулдауне (когда «Создать» нет, а стоит
таймер «Осталось… мин») просто не сработают — это нормально, бот кликнет вхолостую и
пойдёт дальше.

> Отключить авто-крафт целиком — сними галочку в меню `launcher.py` (или
> `CRAFT_ENABLED = False` вверху `omela_bg.py`). Изменить период — поле «крафтить
> каждые N сек» в меню (или `CRAFT_EVERY_SEC` в секундах).

## Что бот делает сам

- **Сбор:** находит ресурс выбранной профессии по цвету (пресет или снятый пипеткой)
  **и по форме**: пятно должно быть плотным, достаточно круглым и **ярче фона**
  (контраст) — так камни отличаются от травы. Кандидаты **ранжируются по
  «уверенности»**, и бот кликает сперва по самым надёжным (не больше
  `DETECT_MAX_RESULTS` за цикл). Запускает добычу (`GATHER_CLICKS` кликов), не тыкает
  то же место повторно (`RECLICK_COOLDOWN` сек).
- **Прокрутка карты (адаптивная):** прокручивает карту колёсиком **плавными шагами**,
  после каждого шага проверяет, что картинка реально сдвинулась, и у края карты
  (низ/верх) **разворачивается** и идёт обратно — «маятник». Так охватывается вся
  высота карты, а прокрутка не «проскакивает» за край вхолостую (`MAP_SCROLL_*`).
- **Окна-ошибки:** жмёт откалиброванную кнопку «закрыть», только когда она красная.
- **Чужие ресурсы:** клик привёл к ошибке → место запоминается и не кликается
  (`SKIP_FAILED_*`), отдельно на каждое положение прокрутки.
- **Бой:** блок + атака по раундам; победа → «выход» → «В охоту».
- **Авто-крафт:** каждые `CRAFT_EVERY_SEC` заходит в панель профессии, жмёт «Создать»
  у каждого рецепта (ждёт перезагрузку экрана между нажатиями) и возвращается к сбору.

## Настройки (вверху `omela_bg.py`)

Параметры, помеченные 🎚, удобнее задавать в меню `launcher.py` (оно пишет их в
`fight_zones.json` → `run_config` и переопределяет одноимённые константы при старте).

| Параметр | Что делает |
|---|---|
| `MAX_RUNTIME_MIN` 🎚 | сколько минут работать, потом «Лимит времени. Стоп.» (по умолч. 240) |
| `PROFESSIONS` | пресеты профессий: диапазоны цвета и форма ресурса (можно править) |
| `DEFAULT_PROFESSION` | профессия по умолчанию, если не выбрана (`herbalist`) |
| `DETECT_SENSITIVITY` 🎚 | чувствительность распознавания: <1 мягче, >1 строже (флаг `--sens` / ползунок в меню) |
| `DETECT_MAX_RESULTS` | сколько самых «уверенных» пятен кликать за один цикл |
| `GATHER_CLICKS` | сколько кликов запускают добычу (обычно из калибровки) |
| `CRAFT_ENABLED` 🎚 | вкл/выкл авто-крафт рецептов в панели профессии |
| `CRAFT_EVERY_SEC` 🎚 | как часто крафтить, сек (по умолчанию 330 = 5 мин 30 сек) |
| `CRAFT_ON_START` 🎚 | крафтить ли сразу при запуске бота |
| `CRAFT_RELOAD_WAIT` | сколько ждать перезагрузку экрана после каждого «Создать» |
| `RECLICK_COOLDOWN` / `RECLICK_RADIUS` | защита от отмены: не тыкать то же место |
| `MAP_REGION` | область карты (обычно из калибровки) |
| `BLOB_*` | форма пятна: размер, `solidity` (плотность), `circularity` (округлость), `contrast` (ярче фона) |
| `EXCLUDE_RANGES` | цвета-исключения (фон/трава) из пипетки-исключения (Этап 0б) |
| `POPUP_CLOSE_TARGET`, `POPUP_RED_FRAC` | кнопка «закрыть» и порог «красноты» |
| `POPUP_USE_GEOMETRY` | запасной авто-поиск окна (ВЫКЛ — может ложно кликать) |
| `SKIP_FAILED_*` | чёрный список чужих ресурсов |
| `MAP_SCROLL_DELTA` / `MAP_SCROLL_SUBSTEPS` | шаг прокрутки и на сколько докруток он дробится |
| `MAP_SCROLL_MOVE_MIN` / `MAP_SCROLL_MAX_POS` | порог «карта сдвинулась» и предел размаха маятника |
| `FIGHT_ENABLED` 🎚 | вкл/выкл авто-бой (остальные `FIGHT_*` — зоны колеса) |
| `SPLINTER_ENABLED` 🎚 | вкл/выкл реакцию на «занозу» / лечение |

## Если что-то не так

- **Бот крутит карту, но НЕ собирает ресурсы** (частая жалоба) — почти всегда бот
  просто **не находит ресурс** и от этого только прокручивает карту. Разбор по шагам:
  1. **Та ли профессия?** Собираешь камни, а стоит травник? — `python omela_bg.py
     --prof geolog` (или Шаг 1 калибровки). Бот теперь пишет в лог, если много циклов
     подряд ничего не видит, и прямо подсказывает, что проверить.
  2. **Не «отравлен» ли игнор?** Если в чёрный список случайно попал цвет самого
     ресурса — бот выбрасывает все находки. Нажми **«Очистить игнор»** в `launcher.py`
     (или введи `c` в Шаге 1.3 калибровки). Бот и сам при старте отбрасывает из игнора
     цвет, совпавший с ресурсом, и пишет об этом — загляни в лог.
  3. **Сними цвет пипеткой** (Шаг 1.2): кликни прямо по ресурсу, который собираешь.
  4. **Смягчи чувствительность:** `python omela_bg.py --sens 0.8` — видит больше.
  5. **Проверь глазами:** `python omela_bg.py --debug` → открой `detect_*.png`
     (зелёные кружки = принято, красные = отсеяно с причиной) и `mask_*.png`.
  6. **Область карты** (Шаг 2) — не смотрит ли бот мимо игрового поля.
- **Бот сам отменяет добычу** — проверь `GATHER_CLICKS` (этап 2) и что
  `POPUP_USE_GEOMETRY = False`; калиброванная точка «закрыть» не даёт ложных кликов.
- **Не закрывает окно «закрыть»** — пройди этап 3 калибровки. Проверить порог:
  открой окно и запусти `python omela_bg.py --debug` — в логе будет «доля красного
  в точке закрыть»; если < `POPUP_RED_FRAC`, уменьши порог.
- **Тыкает мимо ресурсов** — пройди этап 1 (область карты).
- **Не видит нужный ресурс / ловит лишнее (траву, фон)** — три инструмента:
  1. **Пипетка** (`--calib`, Этап 0): сними реальный цвет ресурса — кликай прямо по
     камню в игре. Для камней разного цвета сними несколько образцов.
  2. **Пипетка-исключение** (`--calib`, Этап 0б): если тыкает по траве/фону — кликай
     по ним, чтобы занести в чёрный список.
  3. **Чувствительность** (`--sens`): пропускает → `--sens 0.8` (мягче); ловит лишнее
     → `--sens 1.3` (строже).
- **Как посмотреть, что бот распознаёт:** `python omela_bg.py --debug` — сохранит
  `detect_*.png` (зелёные кружки = принято, красные = отсев с причиной), `mask_*.png`
  (цветовая маска) и в лог выведет причины отсева (contrast/solidity/circularity/…).
  По причинам сразу видно, что крутить: много `contrast`/`solidity`/`circularity` в
  отсеве при реальных камнях → снизь `--sens`; много ложных принятых → подними.
- **Собирает не тот ресурс** — проверь профессию: `python omela_bg.py --prof <имя>`
  или Этап 0 калибровки.
- **Бьёт мимо в бою** — пройди этап 4.
- Лог — `omela_bg.log`.
